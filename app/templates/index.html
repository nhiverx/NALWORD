      Prototype / implementation notes
      • This is a prototype. Outputs are drafts for human review, not verified or certified content.
      • Without Bedrock configured, outputs come from the deterministic mock generators in app/workflow.py.
      • Review records and sessions are stored in memory and are lost when the server restarts. There is no database persistence.
      • Reviewer ID is a free-text field. There is no authentication or multi-user authorization.
      • The system never advances a step on its own. Each transition requires an explicit human decision.
      • The Faithfulness and Compliance Check is advisory. Its detection accuracy and the LLM evaluator's reliability have not been measured.
      • Pre-generation content validation gate (RAG pipeline): retrieved sources older than 1,825 days or below the minimum relevance threshold (0.10) are filtered out before reaching the LLM. This reduces, but does not eliminate, unsupported content.
